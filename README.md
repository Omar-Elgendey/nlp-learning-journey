## 🎯 Purpose

The goal of this repository is to document what I learn while studying NLP and LLM-related concepts.

The focus is on understanding concepts **step by step**, including both the theory and what happens behind the scenes.

The general learning workflow is:

```text
Concept
   ↓
Understand
   ↓
Implement
   ↓
Document
   ↓
Review
```

## 📓 Notes & Notebooks

The repository contains a combination of:

* Learning notes
* Explanations
* From-scratch implementations
* Jupyter notebooks
* Practical experiments

The notebooks focus more on implementation, while the README files are kept concise for revision.
